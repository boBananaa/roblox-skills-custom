# Roblox Skills Custom

A planned collection of seven Roblox development skills for AI coding assistants, maintained by [boBananaa](https://github.com/boBananaa).

**Status: planning.** This repository is a placeholder. No skills are implemented or ready to install yet.

## Planned coverage

- UI and responsive interfaces
- Animations
- Player data and persistence
- Monetization and purchases
- Performance
- Remote events and client-server communication
- Security and server-side validation

The pack will prioritize UI work while supporting the full game development process. The planned approach is to explain implementation plans first, reuse suitable existing frameworks and libraries, and check technical guidance against official Roblox documentation.

## Background

This project was inspired by [sentinelcore/roblox-skills](https://github.com/sentinelcore/roblox-skills). This placeholder contains none of that repository's skill files. Any future reuse will need appropriate permission and attribution.
